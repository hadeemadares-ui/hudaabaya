# 🕌 HUDA ABAYA DUBAI — เว็บไซต์ร้านค้าชุดและน้ำหอมดูไบ

ระบบอีคอมเมิร์ซระดับพรีเมียมสำหรับร้าน **HUDA ABAYA DUBAI** จำหน่ายชุดอาบายะห์ เดรสคัฟทาน และน้ำหอมดูไบแท้

---

## 🌟 ฟีเจอร์หลักในระบบ
- 👗 **ระบบจัดการสต๊อกเสื้อผ้าแยกตามแบบและไซส์**: เลือกไซส์ S, M, L, XL, XXL, Free Size พร้อมเช็คจำนวนสต๊อกคงเหลือของแต่ละไซส์ได้แบบเรียลไทม์
- 💳 **ชำระเงินได้ครบทุกช่องทาง**:
  - พร้อมเพย์ (PromptPay Dynamic QR Code)
  - โอนเงินผ่านธนาคาร + แนบสลิปโอนเงิน (KBANK / SCB / BBL)
  - บัตรเครดิต / เดบิต (Visa, Mastercard, JCB)
  - ชำระเงินปลายทาง (COD)
  - กระเป๋าเงินดิจิทัล (TrueMoney Wallet / Rabbit LINE Pay)
- 📜 **ออกใบเสร็จรับเงินดิจิทัล**: ดาวน์โหลดและพิมพ์ใบเสร็จรับเงินทันทีหลังสั่งซื้อ
- 📦 **ระบบติดตามสถานะพัสดุ (Order Tracking)**: ค้นหาด้วยเลขคำสั่งซื้อหรือเบอร์โทรศัพท์
- 🔐 **ระบบหลังบ้าน Admin Backoffice**: สรุปยอดขาย ตรวจสลิปโอน อัปเดตเลขพัสดุ และปรับสต๊อกสินค้าแยกไซส์

---

## 🚀 วิธีการเปิดใช้งานบนเครื่อง (Local Server)
```bash
# 1. ติดตั้ง Dependencies
cmd /c "npm install"

# 2. เปิดใช้งานในโหมดพัฒนา (Development)
cmd /c "npm run dev"
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

---

## 🌐 วิธีนำขึ้นออนไลน์ให้ลูกค้าจริงใช้งาน (Deployment to Vercel)

1. สร้าง Repository ใหม่ใน [GitHub.com](https://github.com)
2. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
3. ไปที่ [Vercel.com](https://vercel.com) แล้วกด **"Add New Project"** เลือก Repository
4. กด **"Deploy"** ระบบจะสร้างลิงก์เว็บไซต์ออนไลน์พร้อมใช้งานทันทีฟรี!
