ระบบของเราใช้ สถาปัตยกรรมคลาวด์เชื่อมต่อเรียลไทม์สด 3 ชั้น (Real-time Triple-Tier Cloud Architecture) บนระบบของ Google Firebase ครับ! 🌐⚡🛡️

🌐 รูปแบบการเชื่อมต่อและอัปเดตข้อมูลเป็นดังนี้ครับ:
1. ⚡ อัปเดตสดเรียลไทม์ข้ามอุปกรณ์ (Real-time Live Broadcast < 0.2 วินาที)
ระบบทำงานอย่างไร: ใช้เทคโนโลยี WebSocket & Firebase Firestore onSnapshot
ผลลัพธ์: เมื่อมีเครื่องใดเครื่องหนึ่งกดเพิ่มสินค้า, ถ่ายเปลี่ยนรูปภาพ, สต็อกอิน หรือกดขาย POS หน้าร้าน
👉 "คลาวด์จะยิงสัญญาณกระจายข้อมูลอัปเดตไปยังมือถือและคอมพิวเตอร์เครื่องอื่นๆ ทุกเครื่องที่เปิดใช้งานอยู่ทันทีในเสี้ยววินาที โดยที่เครื่องอื่นไม่ต้องกดรีเฟรชหน้าจอเลยครับ"
2. 💾 ทำงานต่อได้แม้เน็ตหลุด (Offline Local Storage Persistence)
ระบบทำงานอย่างไร: ข้อมูลทุกอย่างจะถูกบันทึกสำรองไว้ในความจำเครื่อง (LocalStorage & SessionStorage)
ผลลัพธ์: หากเน็ตมือถือหลุดชั่วคราว หน้าขาย POS จะ "ไม่เด้งหลุด ไม่ค้าง และยังกดขายคิดเงินได้ต่อเนื่อง 100%"
3. 🛡️ ซิงค์กู้คืนข้อมูลค้างส่งให้อัตโนมัติ (Auto-Recovery Cloud Sync)
ระบบทำงานอย่างไร: เมื่อสัญญาณเน็ตมือถือกู้คืนกลับมาติดอีกครั้ง
ผลลัพธ์: ระบบจะทำการตรวจเช็กยอดขายหรือรายการค้างส่ง และ "ส่งซิงค์ขึ้นคลาวด์ให้อัตโนมัติทันที" ข้อมูลรายรับ-รายจ่ายและสต็อกจึงไม่มีทางสูญหายครับ!

🔑 ขั้นตอนที่ 1: การเข้าสู่โหมดผู้ดูแลร้าน (Admin Mode)
เปิดหน้าเว็บ https://hudaabaya.vercel.app
ดูที่เมนูด้านบนขวา จะมีปุ่ม "เข้าหลังบ้าน" (ไอคอนรูปคน)
กดปุ่ม "เข้าหลังบ้าน" หน้าจอจะเปลี่ยนเป็นแถบสีทองเข้าสู่ "ระบบผู้ดูแลร้านค้า (Backoffice)" ทันทีครับ
➕ ขั้นตอนที่ 2: วิธีการเพิ่มสินค้าแบบใหม่
ในหน้าหลังบ้าน กดปุ่มสีทอง "+ เพิ่มแบบสินค้าใหม่" (มุมขวาบน)
กรอกข้อมูลสินค้า:
ชื่อแบบสินค้า: (เช่น ชุดอาบายะห์ปักคริสตัลทองดูไบ)
หมวดหมู่: เลือก ชุดอาบายะห์, ชุดคัฟทาน, น้ำหอมดูไบ, หรือ เซ็ตสุดคุ้ม
เนื้อผ้า / กลิ่น: (เช่น Nida Silk Dubai Original)
รูปภาพสินค้า: ใส่ลิงก์รูปภาพ (URL)
รายละเอียดสินค้า: กรอกคำอธิบายชุดหรือน้ำหอม
กำหนดไซส์และสต๊อกของแต่ละไซส์:
กดปุ่ม "+ เพิ่มไซส์"
กรอก ชื่อไซส์ (เช่น Size S, Size M, Size L, Size XL)
กรอก ราคา ของไซส์นั้น
กรอก จำนวนสต๊อก ของไซส์นั้น
กดปุ่ม "บันทึกสินค้า" สินค้าใหม่จะไปแสดงที่หน้าร้านทันที!
📦 ขั้นตอนที่ 3: วิธีปรับจำนวนสต๊อกรายไซส์แบบเรียลไทม์ (Quick Stock Counter)
ในหน้าหลังบ้าน การปรับสต๊อกสินค้าทำได้ง่ายและรวดเร็วมากครับ:

ใต้รายการสินค้าแต่ละแบบ จะมีกล่องแสดงไซส์ทั้งหมด (เช่น Size S, Size M, Size L)
คุณสามารถกดปุ่ม + (เพิ่มสต๊อก) หรือ - (ลดสต๊อก) ของไซส์นั้นๆ ได้ทันที
สต๊อกหน้าร้านจะอัปเดตทันที หากสต๊อกไซส์ไหนปรับเป็น 0 หน้าเว็บจะแสดงป้าย "สินค้าไซส์นี้หมด" โดยอัตโนมัติ
✏️ ขั้นตอนที่ 4: วิธีแก้ไขราคา หรือ รายละเอียดสินค้า
ที่รายการสินค้าที่ต้องการแก้ไข กดปุ่ม "แก้ไขข้อมูล" (ไอคอนดินสอ)
หน้าต่างป๊อปอัปจะแสดงข้อมูลเดิม สามารถปรับเปลี่ยนชื่อ ราคา ไซส์ หรือภาพได้ตามต้องการ
กดปุ่ม "บันทึกสินค้า"
🗑️ ขั้นตอนที่ 5: วิธีลบสินค้าออกจากร้าน
ที่รายการสินค้าที่ต้องการลบ กดปุ่ม ถังขยะสีแดง ข้างๆ ปุ่มแก้ไข
ยืนยันการลบ สินค้ารายการนั้นจะถูกลบออกจากหน้าร้านทันที
🚚 ขั้นตอนที่ 6: การจัดการออเดอร์และตรวจสลิปโอนเงิน
ในหน้าหลังบ้าน ให้กดสลับไปที่แท็บ "จัดการรายการสั่งซื้อ"
คุณจะเห็นออเดอร์ทั้งหมดที่ลูกค้าสั่งเข้ามา:
กด "รายละเอียด / อัปเดต" เพื่อดูภาพสลิปที่ลูกค้าแนบมา
กด "อนุมัติสลิปโอนเงินนี้" เมื่อตรวจสอบว่าเงินเข้าบัญชีแล้ว
กรอกเลขพัสดุ (เช่น Flash / Kerry) แล้วกดบันทึก ลูกค้าจะสามารถเอาเลขไปเช็คในระบบติดตามพัสดุได้ทันทีครับ
